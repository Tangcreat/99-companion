# 表情包放这里

把图片（png / jpg / gif / webp）放进这个目录，然后到「设置 → 表情包 → 重新扫描」。

## 命名约定（重要）

文件名前缀就是**情绪标签**，角色按当轮情绪挑图：

    开心_01.png
    无语_汗.png
    困倦_打哈欠.gif
    亲密_抱抱.png

识别之后，她判断出「对方现在需要安慰」就会去「安慰」类里找图；
情绪对不上一张都不发——硬塞不搭的图比不发更尴尬。

## 目录即分类

    stickers/
    ├── 示例表情包/       ← 一个目录 = 一个表情包集
    └── 我的图包/

## 建议

- 短边 ≥ 400px，太小放大后糊
- 也支持按情绪分子目录（`开心/xx.png`），目录名会被当情绪兜底
- 文件太多不会拖慢聊天，索引是增量的，只处理新文件
